# Wanderlust 🌍

A Netflix-style interactive travel guide showcasing four dream destinations — presented as a cinematic series you can browse, play, and explore.

## Destinations

| Profile | Destination | Highlights |
|---------|-------------|------------|
| 🪸 Lakshadweep | India's coral paradise | Turquoise lagoons, pristine reefs, zero crowds |
| 🌅 Greece | Santorini & the Aegean | White domes, caldera sunsets, infinity pools |
| 🌌 Iceland | Fire, ice & aurora | Northern Lights, glaciers, waterfalls, geothermal spas |
| 🦘 Australia | The Wide Open South | Opera House, Uluru, Great Barrier Reef, outback |

## Tech Stack

- **React** + **TypeScript** + **Vite**
- **TanStack Router** for client-side routing
- **Framer Motion** for animations
- **Tailwind CSS** + **shadcn/ui** for styling
- **Unsplash** for all images (free, no auth needed)

## Getting Started

```bash
npm install
npm run dev
```

No environment variables needed. All images load from Unsplash's public CDN.

## Deployment

```bash
npm run build
```

Deploy to Vercel, Netlify, or any static host. Zero secrets required.
